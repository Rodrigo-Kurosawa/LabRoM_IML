## Pipeline (SexClassifierAction.runPipelineAsync)

```
Step 1  DicomExtractor   → sc_0000.png …    (pure-Java SC detect + PythonWorker.extract)
Step 2  PivotDetector    → pivo_0000.png … (PythonWorker.pivot, ResNet-50, ±5 window)
Step 3  SexClassifier    → labels + heatmaps (PythonWorker.classify, YOLOv8 final.pt)
Step 4  buildComposites  → comp_0000.png …  (pure Java BufferedImage, side-by-side)
```

All Python inference goes through one long-lived child process owned by
`PythonWorker` (singleton). On plugin activation
(`SexClassifierToolBarFactory.activate()`) the worker is pre-warmed on a
background daemon thread — `torch`, `ultralytics`, ResNet-50 weights and
the YOLOv8 + Grad-CAM hooks are all loaded before the user's first click.
Subsequent clicks reuse everything in memory until JVM shutdown.
Wire protocol is documented at the top of `inference_worker.py`.

Inference-stage optimisations applied (all in `inference_worker.py` /
`PivotDetector.java`): batched forward passes (`PIVOT_BATCH_SIZE=16`),
`ThreadPoolExecutor` for parallel PIL preprocessing, stride-2 pivot scan
(`PIVOT_STRIDE=2` in `PivotDetector` — scan every other image and accept
the picked window being ±1 slice off optimal).

All temp files live in `Files.createTempDirectory("sex_classifier_")`. They are cleaned by a static JVM shutdown hook — never in a `finally` block (would break the UI).

**Roadmap for further changes:** see `OPTIMIZATION_ROADMAP.md` at repo root.

## Known Gotchas

### 1. main.wxs must be WiX3 format (NOT WiX4)
`jpackage` applies an XSLT to convert WiX3 → WiX4. If `main.wxs` is already WiX4, or contains `<Binary Id="JpCaDll" SourceFile="wixhelper.dll"/>`, you get `WIX0103`. The fix: use `<Product Id="..."><Package .../></Product>` structure, no wixhelper reference. Canonical files live in `build/msi/*/main.wxs` and are overwritten by `distribute.ps1` before jpackage runs.

### 2. Python embeddable `.pth` BOM corruption
`Set-Content -Encoding UTF8` writes a UTF-8 BOM → Python reads `﻿python312.zip` instead of `python312.zip` → `No module named 'encodings'`. Fix: `[System.IO.File]::WriteAllLines(path, lines, (New-Object System.Text.UTF8Encoding $false))`.

### 3. Temp dir must NOT be deleted at pipeline end
Files in the temp dir are referenced by result cards in the UI. Deleting them at `finally` breaks image display. Cleanup only at JVM shutdown (static hook in `SexClassifierAction.java`).

### 4. MODEL_FILENAME = "final.pt" (not "best.pt")
Changed intentionally. `distribute.ps1` copies all `*.pt` files, but the code loads only `final.pt`. If model fails to load, check this constant first.

### 5. Git push credentials
Remote: `https://github.com/Rodrigo-Kurosawa/LabRoM_IML.git`. Windows Credential Manager may store `Davi-nAraujo` instead.
Fix: `git remote set-url origin https://Rodrigo-Kurosawa@github.com/Rodrigo-Kurosawa/LabRoM_IML.git`

### 6. PowerShell line continuation is backtick, not backslash
Bash `\` → PowerShell `` ` ``. Using `\` silently joins the next line as a separate statement.

### 7. Python runtime cache
`%LOCALAPPDATA%\LabRoM\python-runtime` is cached. If `import torch` passes, Phase 5 is skipped entirely (saves 15–30 min). Delete this folder to force reinstall.
